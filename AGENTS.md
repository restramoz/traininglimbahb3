# Sertifikasi K3 Konstruksi — Project Instructions

## Project Scope
Build a standalone Laravel 13 website for Sertifikasi K3 Konstruksi.
Target domain: sertifikasik3konstruksi.my.id.
Target runtime: PHP 8.3 compatible.
Programs:
- Training K3 Konstruksi Muda
- Training K3 Konstruksi Madya
- Training K3 Konstruksi Utama

## Design
- Mobile-first, responsive, conversion-focused.
- Industrial and professional visual identity.
- Dark navy, white, concrete gray, safety-yellow accents.
- Use construction-related imagery where appropriate.
- Clear WhatsApp calls to action.

## Work Rules
- Work only inside this workspace.
- NEVER modify or deploy the existing live P3K project.
- Reuse existing dependencies and patterns where appropriate.
- Do not assume paid services, APIs, or hosting.
- Ask approval before paid actions, destructive changes, or deployment.
- Never expose secrets, credentials, or private contact data.
- Do not invent accreditation, certification authority, prices,
  durations, prerequisites, curriculum, or partnerships.
- Keep K3 content specific; do not copy P3K content verbatim.
- Use accessible semantic HTML and secure Laravel conventions.
- Apply login rate limiting and protect admin routes.
- Run relevant tests and report actual results.
- Keep changes minimal, complete, and maintainable.

## Roles
### Frontend
Own Blade views, responsive layout, design tokens, accessibility,
visual consistency, and conversion-focused interactions.

### Backend
Own Laravel routes, controllers, validation, models, services,
security, and data handling.

### QA
Independently inspect changes, test important user flows,
check responsive behavior, identify security risks, and report
reproducible findings. Do not claim tests passed unless executed.

## Workflow
1. Inspect the workspace before changing files.
2. Agree on implementation scope.
3. Implement the smallest complete solution.
4. Run checks and tests.
5. Summarize changed files, test results, and remaining blockers.
